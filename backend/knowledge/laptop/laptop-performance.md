# Laptop Performance Troubleshooting

## Purpose

Use this guide when a corporate laptop is unusually slow, freezes, or takes significantly longer than normal to start applications.

## Troubleshooting

### 1. Restart the laptop

Save work and restart the device.

A restart can clear temporary resource pressure and complete pending operating-system operations.

### 2. Check resource usage

Use the approved operating-system resource monitor to inspect CPU, memory, disk, and application usage.

Look for applications consuming unusually high resources.

### 3. Close unnecessary applications

Close applications and browser tabs that are not required.

Do not terminate security or endpoint-management processes unless instructed by the service desk.

### 4. Check available storage

Verify that the system drive has reasonable free space.

Do not manually delete unknown system files.

### 5. Check for pending updates

Allow approved operating-system and corporate application updates to complete.

Do not disable update mechanisms to improve short-term performance.

### 6. Check whether the issue is application-specific

If only one application is slow, record the application name and version and report the behavior to the relevant support team.

If the entire device is slow, provide the time the issue started and whether it occurs after every restart.

### 7. Escalate

Escalate when:

- The laptop repeatedly freezes or crashes.
- Disk errors or hardware warnings appear.
- Performance remains poor after restart and basic checks.
- Multiple users report the same application performance issue.
- The device becomes unusable for business work.

## Information to provide

Include the device name or asset identifier, affected application, approximate start time, symptoms, and any visible error message.
