# Corporate Password Reset

## Self-service password reset

Employees can reset their corporate password through the approved password-reset workflow.

The employee must explicitly request the password reset.

## Verification

The identity verification step must complete successfully before the password reset operation is executed.

## Failure

If the password reset provider fails, do not claim that the password was changed.

The request should be escalated according to the password-reset incident procedure.
