# Wi-Fi Troubleshooting

## Purpose

Use this guide when a corporate laptop cannot connect to an approved Wi-Fi network or repeatedly loses the connection.

## Troubleshooting

### 1. Confirm Wi-Fi is enabled

Verify that Wi-Fi is enabled and airplane mode is disabled.

### 2. Confirm the correct network

Select the organization's approved corporate Wi-Fi network.

Do not connect to unknown or unapproved networks for corporate work unless company policy explicitly permits it.

### 3. Reconnect

Disconnect from the affected network and reconnect using the approved corporate credentials.

If the network requires certificate-based authentication, do not bypass certificate warnings.

### 4. Check signal and location

Move closer to an approved access point if the signal is weak.

If the issue occurs only in one physical area, provide the location to the service desk because the issue may be related to wireless coverage.

### 5. Restart network connectivity

Temporarily disable and re-enable Wi-Fi.

If the issue persists, restart the laptop.

### 6. Check whether the problem is isolated

Test another approved corporate network if available.

If multiple employees in the same area experience the issue, report it as a possible network incident rather than repeatedly changing the device configuration.

### 7. Escalate

Escalate when:

- The corporate network is unavailable for multiple users.
- Authentication repeatedly fails.
- The device cannot detect any approved corporate networks.
- Certificate or endpoint-management errors are displayed.
- Connectivity is required for a critical business application.

## Security

Never disable endpoint security, certificate validation, or corporate network protections to make Wi-Fi connect.
