# Software Installation Procedure

## Purpose

Use this guide when an employee needs approved software installed on a corporate device.

## Before Installation

Confirm:

- The software name and version.
- The business purpose.
- Whether the software is approved by the organization.
- Whether the user is entitled to the software license.
- Whether administrator approval is required.

## Standard Procedure

### 1. Use the approved software catalog

Install software through the organization's approved software catalog or managed deployment mechanism whenever available.

### 2. Verify the requested application

Confirm that the application name and requested version match the approved request.

Do not install software downloaded from an unknown website when an approved corporate package exists.

### 3. Submit an access or installation request

If the application requires approval or licensing, submit the appropriate service request with the business justification.

### 4. Allow managed installation

Do not disable endpoint security or manually bypass administrative controls.

Allow the managed deployment process to complete.

### 5. Validate

After installation:

- Launch the application.
- Confirm that it opens successfully.
- Confirm that the required corporate account or license is available.
- Record any installation error.

## Escalation

Escalate when:

- The application is not present in the approved catalog.
- The license is unavailable.
- Installation requires administrator privileges not granted to the user.
- The managed deployment repeatedly fails.
- Security software blocks the installation.

## Security

Do not provide administrator credentials to employees for self-installation. Do not bypass endpoint security controls.
